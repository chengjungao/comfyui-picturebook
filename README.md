# 绘本工坊

**用你自己电脑上的 AI，把一个故事做成一本能打印的绘本。**

界面上写分镜 → 本机出图 → 排版 → 导出 PDF。全程离线，不联网、不排队、没有额度。

## 这个项目解决什么问题

用 AI 出插画不难，难的是**做成一本书**：

| 卡在哪 | 这里怎么处理 |
|---|---|
| 每一页的主角长得不一样 | 先出一张**角色定妆照**，之后每一页都拿它当参考图。这是全书一致性的唯一来源 |
| 画面里的字总是写错 | **不让模型写字**。插图整幅放上部，正文另排一条文字带，改错别字是秒级的 |
| 一张一张点，点到手酸 | 全部任务一次压进队列，让显卡不空转，统一等结果 |
| 排好版发现要改一句话，得重画图 | 排版是独立的一步，改文字重新排一次就行，**不用重画图** |
| 云端一套绘本要分好几天做 | 本地跑，想重出几次就重出几次 |

## 三步开始

### 1. 准备 ComfyUI 和模型

本项目**不包含** ComfyUI 和模型文件，需要先装好。完整步骤见
**[docs/环境准备.md](docs/环境准备.md)**，大意是：

1. 装 ComfyUI（Windows 有便携版，解压即用）
2. 下载三个模型文件放进对应目录
3. 启动 ComfyUI

### 2. 启动绘本工坊

| 系统 | 怎么做 |
|---|---|
| **Windows** | 双击 `start.bat` |
| **macOS / Linux** | 终端里跑 `./start.sh` |
| 通用 | `python app.py` |

浏览器会自动打开界面。关掉那个黑窗口就停止。

> 需要 Python 3.8 以上。**不需要 `pip install` 任何东西** —— 这个项目只用 Python 标准库。

### 3. 在界面里跟着四步走

```
1 环境  →  确认 ComfyUI 连上了、模型选对了
2 分镜  →  写每一页画什么、说什么
3 出图  →  先出定妆照看一眼，满意了再批量出全部内页
4 成书  →  排版 → 导出 PDF
```

先跑一次自检，它能直接告诉你缺什么：

```bash
python app.py --check
```

---

## 界面里最关键的那一步

**先出一张角色定妆照，人眼看一眼确认，再批量出内页。**

定妆照是整本书角色一致的唯一来源。它错了，后面每一页都跟着错，而重出十几页很费时间。
所以顺序不能反，也别跳过「看一眼」。

出好之后的每一步，界面都会告诉你当前在做什么、还剩几页、用了多少秒。

## 目录结构

```
comfyui-picturebook/
├── app.py                 启动入口（--check 自检 / --example 复制示例）
├── start.bat / start.sh   一键启动
├── config.json            设置（模型文件名、画幅、开本…首次运行自动生成）
├── studio/                核心代码
│   ├── comfy.py           ComfyUI 客户端（提交、轮询、取图、上传参考图）
│   ├── workflows.py       构造出图工作流
│   ├── pipeline.py        出图编排
│   ├── project.py         工程文件读写与校验
│   ├── bookbuild.py       排版，产出 HTML
│   ├── pdf.py             调无头浏览器导出 PDF
│   └── web.py             本地服务与界面
├── web/                   界面（原生 HTML/CSS/JS，无框架无 CDN）
├── workflows/             给 ComfyUI 界面用的工作流（可直接拖进去）
├── examples/              示例工程：分镜 + 正文 + 成品预览
└── docs/                  环境准备与常见问题
```

你自己的书会放在单独一个文件夹里：

```
我的绘本/
  project.json   分镜、正文、风格，全在一个文件里
  img/           出好的图（char_sheet.png 就是定妆照）
  book.html      排版结果
  我的绘本.pdf    成品
```

## 两份工作流

`workflows/` 里是界面版工作流，可以直接拖进 ComfyUI 手动调参数：

| 文件 | 用途 |
|---|---|
| `1-角色定妆照.json` | 出全书唯一的那张角色主视觉（文生图，横版 1344×768） |
| `2-内页插图.json` | 拿定妆照当参考图，逐页出插图（图生图） |

两个文件里都有「说明」节点，写着三条铁律，建议先读：

1. **定妆照必须是横版** —— 内页尺寸跟随第一张参考图，定妆照是方的全书就是方的
2. **`denoise` 保持 1.0** —— 调低不是「改得少一点」，是画面结构性崩坏
3. **别把上一页的产物当参考图** —— 误差会逐页累积，几页后主角就认不出来了

只用界面、不用这个项目的人也欢迎拿走这两份工作流。

## 常见问题

出图报 500 / 连不上 / 转不出 PDF / 想换画幅或换模型 —— 见
**[docs/常见问题.md](docs/常见问题.md)**。

最常遇到的两个：

- **界面右上角显示「ComfyUI 连不上」**：ComfyUI 没启动。先启动它，再点一下右上角重新检查。
- **自检说「模型里没有 xxx.safetensors」**：`config.json` 里的文件名和 ComfyUI 实际认识的
  不一致。自检会列出实际可选的名字，在界面上选一下就行。
