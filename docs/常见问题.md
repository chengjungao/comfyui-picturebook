# 常见问题

按症状查。每条都给出「为什么会这样」和「怎么解决」。

---

## 连不上 / 报错

### 界面右上角显示「ComfyUI 连不上」

**ComfyUI 没在运行。** 双击便携版目录里的 `run_nvidia_gpu.bat`，
等它打印出 `To see the GUI go to: http://127.0.0.1:8188`，
再点界面右上角重新检查。

那个黑窗口必须一直开着 —— 关掉它 ComfyUI 就停了。

### 明明启动了，却报 502 或「积极拒绝」

两个可能：

1. **端口不对。** 确认 ComfyUI 输出的是 `8188`，如果是别的端口，
   在界面「设置」里把「ComfyUI 地址」改对。
2. **系统代理。** 如果开了代理软件，它可能拦截本机回环请求。
   这个项目已经在代码里绕过了（`ProxyHandler({})`），
   但如果你在别的地方手搓脚本，记得加 `--noproxy '*'`。

### 出图报 500，看不到详情

ComfyUI 的 500 响应体里通常不带信息，**要去黑窗口里看 traceback**。

按经验排序，三种原因：

| 黑窗口里的关键词 | 原因 | 解法 |
|---|---|---|
| `AttributeError: 'str' object has no attribute 'get'` | 提交的 JSON 顶层混进了注释之类的非节点键 | 用这个项目自带的脚本不会遇到；手改工作流时注意 |
| 找不到节点 / `class_type` 不认识 | 该节点所属的插件没装，或节点名拼错 | 换用 `workflows/` 里那两份，它们只依赖 ComfyUI 本体 |
| `No module named 'triton'` | 一般是警告不是错误，可忽略 | — |
| `OSError: [Errno 22] Invalid argument`，节点是 `KSampler` | 见下面单独一条，症状很误导 | — |

### 报错节点是 KSampler，错误是 `OSError: [Errno 22] Invalid argument`

这个报错**跟图、跟模型、跟显卡都没关系**，它甚至还没开始采样。

采样每一步都要往控制台刷一行进度条。如果 ComfyUI 的输出没有接收端
（比如被人用 `... | head -40` 这种管道拉起，管道提前关掉了；
或者被某个脚本以后台方式启动但没接管输出），
刷进度条就会抛 `Invalid argument`，整个任务停在这里。

完整调用栈的最后几帧长这样，认准它就不会搞错：

```
comfy/utils.py   model_trange → pbar = trange(...)
tqdm/std.py      status_printer → sys.stderr.flush()
ComfyUI/app/logger.py  flush()
→ OSError: [Errno 22] Invalid argument
```

**解法：老老实实双击 `run_nvidia_gpu.bat`，让那个黑窗口一直开着。**
不要用管道接它、不要重定向到某个会提前关闭的地方。
如果你确实需要把日志存下来，用 `> 日志文件 2>&1`（普通文件重定向没问题），
别用 `| head`、`| tail` 这类会在中途退出的管道。

## 画得不对

### 每一页的主角都不一样 / 越画越不像

先检查一件事：**是不是把上一页的产物也当参考图传进去了？**

这是最常见的原因。上一页的细微偏差会进入下一页的参考段，再被放大，
几页之后主角就变成另一个人了。

正确做法：**每一页都只带同一张定妆照**（`char_sheet.png`）。
本项目默认就是这么做的，别去「优化」它。

如果只带定妆照还是漂：

- 让定妆照更干净（全身、略侧身、中性背景，别自带复杂场景）
- 换个 seed 重出一张定妆照，挑最满意的
- 复杂动作 / 多角色同框 / 极端视角这几类场景，本来就是弱项

### 画面里出现错别字

**不要指望模型写对中文。** 这个项目的做法是让模型**完全不写字**：

- 出图提示词里写死「画面内没有任何文字」
- 正文另排一条文字带，在图下面

所以正常情况下你不会看到错字。如果你**主动**让模型写字了（比如让它画一块招牌），
那出现错字是预期内的。

改一个错别字的成本是秒级的，重画一张图的成本是分钟级的 —— 这就是为什么要分开。

### 插图被裁掉了一块

正常不该发生。这个项目的版式是「插图整幅不裁 + 独立文字带」。

如果发生，说明插图特别高（竖版）。排版时插图区高度会按第一张图的比例算，
如果算出来超过页面高度的 92%，会自动改成按高度排、留出文字带 ——
这种情况下会有轻微裁切。

想彻底避免：**让所有插图保持同一个比例**（定妆照的比例决定了全部内页的比例）。

## 慢 / 跑不动

### 第一张图特别慢，要两分钟

正常。**90 多秒花在加载和编译 16 GB 权重上。**

第二张开始 40 秒左右，连续出图能到 25 秒左右。
第一张慢不代表你的卡不行。

### 出图速度明显低于预期

按顺序排查：

1. **是不是在跑 CPU 版？** ComfyUI 启动时如果打印的是 `run_cpu`，
   或者自检里提示「跑在 CPU 上」，那就是没用到显卡。
   要用 `run_nvidia_gpu.bat` 启动。
2. **显卡是不是被别的程序占着？** 同时开着游戏或别的 AI 工具会抢显存。
3. **是不是在进行内存换页？** 黑窗口里频繁出现 loading / unloading 说明显存不够，
   考虑换用 `w4a8` 版本的文字编码器省 3 GB。

### 显存不够（OOM）

- 换 `qwen3vl_8b_w4a8.safetensors` 当文字编码器（省约 3 GB）
- 关掉其他吃显存的程序
- 画幅调小（比如从 1344×768 降到 1024×576）

## 成书 / 排版

### 转不出 PDF

**没找到 Chrome 或 Edge。** 自动转 PDF 靠的是浏览器的「打印成 PDF」能力。

两条路：

1. 装一个 Chrome 或 Edge（装了就能自动转）
2. **手动转**：在界面点「在浏览器里预览」打开排版结果，
   按 `Ctrl+P`，目标选「另存为 PDF」，纸张尺寸选「自定义」、
   方向「横向」、边距「无」，保存

### PDF 里的字体不对 / 变成方块

排版用的是系统字体（楷体、方正粗黑宋）。Windows 和 macOS 自带楷体，
Linux 上可能没有，会退到默认字体。

改字体：编辑 `config.json` 里的 `book.text_font` 和 `book.title_font`，
填你系统里有的字体名。

### 想改开本大小

编辑 `config.json`：

```json
"book": {
  "page_w_mm": 240,
  "page_h_mm": 180
}
```

⚠️ 改开本要**同时**看插图比例。插图区高度是按页面宽度 × 图高比算的，
所以竖版开本配横版插图会留很多白。

### 版权页上的页数 / 尺寸怎么写

照抄示例最省事，但**示例里的数字是那本书的**。别再手填，写占位符让排版自己算：

| 你写的 | 换成 |
|---|---|
| `{页数}` | 全书页数（含封面封底，不含版权页） |
| `{尺寸}` | 插图尺寸，如 `1344 × 768` |
| `{开本}` | 页面尺寸，如 `240 × 180 mm` |
| `{书名}` | 工程里的书名 |
| `{作者}` | 工程里的署名 |

比如写一行 `全书 {页数} 幅插图，{尺寸}`，排版时会变成
`全书 14 幅插图，1344 × 768`。没有占位符的行原样输出。

### 想改插图比例（横版 / 方版）

改 `config.json` 里的 `generate.width` / `generate.height`，然后
**重新出一张定妆照** —— 内页比例跟着定妆照走。

只改内页的设置是没用的，因为内页尺寸取自参考图。

## 别的

### 一页不满意，只想重出那一页

在「分镜」页找到那一页，点它图片下面的「重画」。
也可以直接改这一页的画面描述再重画。

重出单页成本很低（几十秒），不用整本重来。

### 改了正文，要重画图吗

**不用。** 排版是独立的一步，改完正文重新点一次「排版」就行。

这也是为什么正文不让模型画在图里。

### 工程文件在哪，怎么备份

你的书在启动时指定的那个文件夹里（默认是 `我的绘本/`）：

```
我的绘本/
  project.json   ← 分镜、正文、风格都在这里，是唯一的文字来源
  img/           ← 出好的图
  book.html
  我的绘本.pdf
```

**备份只要复制整个文件夹。** 或者只留 `project.json` + `img/`，
随时能重新排出书来。

（`img/` 里体积大，如果只是想存分镜，`project.json` 一个文件就够了。）

### 想换电脑 / 分享给朋友

整个项目文件夹拷过去，另外装好 ComfyUI 和模型即可。
`config.json` 里的模型文件名如果在对方机器上不同，自检会提示。
