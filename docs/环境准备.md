# 环境准备

绘本工坊本身只是一个界面和调度器，**出图这件事是 ComfyUI 干的**。
所以第一次用之前，需要先把 ComfyUI 和模型准备好。做一次就够，之后一直能用。

预计耗时：**下载模型 25 分钟左右**（17 GB，取决于网速），其余都是几分钟的事。

---

## 一、硬件要求

| 项 | 要求 |
|---|---|
| 显卡 | **NVIDIA，显存 12 GB 以上**（16 GB 稳妥）。实测这套组合峰值占用 12.2–12.6 GB |
| 硬盘 | 模型 17 GB ＋ 出图若干，建议留 30 GB |
| 内存 | 16 GB 以上（ComfyUI 会做内存与显存之间的换页） |
| 系统 | Windows / Linux / macOS 都行 |

没有独显也能跑，但会退到 CPU，一张图要几分钟到十几分钟，体验很差，不建议。

---

## 二、装 ComfyUI

### Windows（推荐，最省事）

1. 到 ComfyUI 官方仓库的 Releases 页下载 **Windows 便携版**
   （文件名类似 `ComfyUI_windows_portable_nvidia.7z`）
2. 用 7-Zip 解压到一个**路径里没有中文和空格**的地方，比如 `D:\ComfyUI_windows_portable`
3. 先不要启动，接着放模型

### macOS / Linux

按官方仓库的说明走。macOS 上这条路可用的模型和速度都不同，请自行确认。

---

## 三、下载模型（三件套）

ComfyUI 跑 Qwen-Image-2.1 需要**三个文件**，分别放三个目录。

**来源（选一个）：**

| 站点 | 地址 | 说明 |
|---|---|---|
| **ModelScope（魔搭）** | https://www.modelscope.cn/models/Comfy-Org/Qwen-Image-2.1 | 国内直连快，推荐 |
| HuggingFace | https://huggingface.co/Comfy-Org/Qwen-Image-2.1 | 国内可能连不上 |

进 **Files（文件）** 页，按下面的路径逐个下载：

| 文件 | 大小 | 放到这里 |
|---|---|---|
| `qwen_image_2.1_int8_convrot.safetensors` | 6.76 GB | `ComfyUI/models/diffusion_models/` |
| `qwen3vl_8b_int8_convrot.safetensors` | 8.71 GB | `ComfyUI/models/text_encoders/` |
| `qwen_image_2.1_vae_bf16.safetensors` | 0.63 GB | `ComfyUI/models/vae/` |

Windows 便携版的话，完整路径就是：

```
D:\ComfyUI_windows_portable\ComfyUI\models\
    ├── diffusion_models\qwen_image_2.1_int8_convrot.safetensors
    ├── text_encoders\qwen3vl_8b_int8_convrot.safetensors
    └── vae\qwen_image_2.1_vae_bf16.safetensors
```

**三个子文件夹如果不存在，自己新建。** 结构要对上，别把三个文件都堆在一个目录里。

### 两个常见坑

- **一定要下完整的权重文件。** 有些下载方式拿到的是几十字节的「指针文件」（LFS pointer），
  放进去 ComfyUI 会报错。正确的大小见上表。
- **别下错量化版本。** 文件名要能和上面三个对上。想要更省显存，可以下
  `qwen3vl_8b_w4a8.safetensors` 替掉 int8 那个文字编码器（省约 3 GB），
  但要在界面里把「文本编码器」也一起换成新文件名，**两个要配对**。

### 不需要下的东西

| 文件 | 为什么不装 |
|---|---|
| `*_pe_t2i` / `*_pe_i2i`（提示词增强器，各约 8.8 GB） | 官方模板默认关闭。**省下 17.6 GB**，装上反而多一层不确定性 |
| `fun_controlnet_union`（约 3.5 GB） | 角色漂移严重时的补强手段，一般用不到 |

## 四、启动 ComfyUI

**Windows：** 双击便携版目录里的 `run_nvidia_gpu.bat`。

看到这样的输出就对了：

```
Total VRAM 16376 MB, total RAM ...
Starting server
To see the GUI go to: http://127.0.0.1:8188
```

**这个黑窗口要一直开着。** 关掉它 ComfyUI 就停了，绘本工坊也就连不上了。

首次启动会慢一些（要初始化依赖），几十秒到一两分钟。

---

## 五、验证

回到绘本工坊目录，跑一次自检：

```bash
python app.py --check
```

正常的话长这样：

```
  浏览器      : C:\Program Files\Google\Chrome\Application\chrome.exe
  ComfyUI     : http://127.0.0.1:8188
    ✓ 已连通（ComfyUI 0.3x.x / Python 3.1x.x）
    显卡：NVIDIA GeForce RTX 4080  显存 16.0 GB（空闲 15.2 GB）
    队列：执行中 0 / 等待 0
  模型        :
    ✓ 扩散模型：qwen_image_2.1_int8_convrot.safetensors
    ✓ 文本编码器：qwen3vl_8b_int8_convrot.safetensors
    ✓ VAE：qwen_image_2.1_vae_bf16.safetensors
```

哪里有 ✗ 它会直接告诉你缺什么。三种常见情况：

| 提示 | 怎么办 |
|---|---|
| `连不上 ComfyUI` | ComfyUI 没启动，或者那个黑窗口被关了。启动后重跑自检 |
| `模型里没有 xxx.safetensors` | 文件名对不上。自检会列出**实际可选**的名字，在界面上选一下就行 |
| `没找到 Chrome 或 Edge` | 不影响出图和排版，只是没法自动转 PDF。装一个浏览器即可，或者手动打印 |

---

## 六、第一次出图要等久一点

**第一次出图大约 2 分钟**，其中 90 多秒花在加载和编译 16 GB 权重上。
第二次开始每张 **40 秒左右**（连续出图 25 秒左右），这是正常节奏。

第一次跑完等了两分钟就以为「这卡跑不动」是最常见的误判。
