# 两份界面工作流

这两份是给 **ComfyUI 界面**用的，可以直接拖进窗口，手动调参、试提示词。

| 文件 | 用途 |
|---|---|
| `1-角色定妆照.json` | 出全书唯一的那张角色主视觉（文生图） |
| `2-内页插图.json` | 拿定妆照当参考图，逐页出插图（图生图） |

两份里面都有一个**「说明」节点**，写着三条铁律，导入后先读那个。

---

## 怎么用

1. 启动 ComfyUI，打开 http://127.0.0.1:8188
2. 把 json 文件**拖进浏览器窗口**
3. 读一下「说明」节点
4. 改提示词 → 点 `Queue`

出好的图在 `ComfyUI/output/` 里。

---

## 和绘本工坊的关系

| | 绘本工坊（这个项目） | 这两份工作流 |
|---|---|---|
| 怎么驱动 | 走 API，自动批量出图 | 在界面里手点 |
| 适合 | 已经定好分镜，要把整本出完 | 试提示词、调参数、单张精修 |

**两者用的是同一套参数**，所以你在界面里试出来一条好提示词，
直接抄进绘本工坊的「画面描述」里就行。

---

## 三条铁律（摘要）

1. **定妆照必须是横版** —— 内页尺寸跟随第一张参考图
2. **`denoise` 保持 1.0** —— 调低不是「改得少一点」，是画面结构性崩坏
3. **别把上一页的产物当参考图** —— 误差会逐页累积

完整说明在 json 里的「说明」节点中。
